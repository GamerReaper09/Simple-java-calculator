# Java calculator
It is literally just a simple calculator made with javafx.
Works a little bit differently than a normal calculator tho and sadly has no keybinds (only mouse).
This calculator makes it easier to modify numbers without having to delete the whole number which maybe can be useful for some.
You can also run the app in dark mode by adding "dark" as an argument when running.

## Setup
* Download .zip from releases
* Unzip folder wherever you want the program.
* Run with the exe
* Optionally run dark mode by running the Darkmode.bat
